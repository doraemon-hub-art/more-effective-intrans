# 功能设计及实现

## 输入拼音转英文

> 目标

- 根据拼音转换成对应的英文；

> 处理流程

1. 快捷键触发输入框;
2. 输入拼音，结束回车确定;
3. 弹出三个可选项 （后期更多可配置）;
4. 选择，将翻译结果输入到原本焦点处; 

> 实现方式

- 现成的翻译接口集成，支持此功能;
- 先将拼音转文字，再次发送调用翻译api;
- 直接调用大模型api实现预设流程，直接给出翻译结果；
